# RepFlow - Скрипт для автоматической ловли репортов в SAMP 📡

**RepFlow** — это мощный скрипт для MoonLoader (SAMP), автоматизирующий процесс отправки команды `/ot` для ловли репортов на серверах Arizona RP и подобных проектах. Скрипт предлагает интуитивно понятный интерфейс на базе ImGui, гибкие настройки, поддержку профилей и автоматическое управление.

## Основные возможности 🌟

- Автоматическая отправка команды `/ot` с настраиваемым интервалом (секунды или миллисекунды).
- Обнаружение репортов в чате по ключевой фразе `[Репорт] от Имя_Фамилия`.
- Автоматическая обработка диалога 1334 для принятия репортов с подсчётом принятых.
- Автостарт ловли после заданного тайм-аута без активности.
- Настраиваемая клавиша активации (по умолчанию `Z`).
- Информационное окно с отображением статуса, времени работы, попыток и принятых репортов.
- Поддержка до трёх профилей настроек с автоматическим сохранением.
- Сохранение настроек в файл `RepFlowCFG.ini`.
- Интерфейс ImGui с вкладками: "Флудер", "Настройки", "Информация", "Статистика", "ChangeLog".
- Выбор цветовых тем: "Космос", "Закат", "Неон", "Лаванда", "Графит".
- Логирование событий в `repflow.log` и принятых репортов в `repflow_reports.log`.
- Защита от флуда с настраиваемой паузой.
- Автообновление через `/update` или при запуске.
- Сброс настроек через меню "Настройки".
- Расширенная статистика: среднее время между `/ot`, попытки, флуды и успехи.
- Команда `/arepstats` для быстрого просмотра статистики в чате.
- Вопросики (подсказки) в меню настроек для упрощения использования.

## Требования 🛠️

- **SAMP**: Установленный клиент San Andreas Multiplayer.
- **MoonLoader**: Версия 0.26 или выше.
- **Библиотеки**:
  - `mimgui`
  - `samp.events`
  - `vkeys`
  - `encoding`
  - `inicfg`
  - `ffi`
  - `fAwesome6` (иконки FontAwesome).

Убедитесь, что все зависимости установлены через `mlupdater` или вручную.

## Установка 🚀

1. Скачайте файл `!RepFlow.lua` из последнего релиза.
2. Поместите его в папку `moonloader` вашей установки GTA:SA.
3. Убедитесь, что все зависимости установлены в папке `moonloader/lib`.
4. Запустите игру. При успешной загрузке скрипт выведет сообщение:  
   `[RepFlow]: Скрипт загружен. Активация меню: /arep`.

## Использование 🎮

### Активация
- **Команда:** Введите `/arep` в чате для открытия меню.
- **Клавиша:** Нажмите `Z` (по умолчанию) для включения/выключения ловли.
- **Обновление:** Используйте `/update` для ручной проверки обновлений.

### Настройки
- **Интервал `/ot`:** Настройте в "Флудер" (1–9999 сек/мс).
- **Пауза после флуда:** Установите в "Флудер" (1–60 сек).
- **Тайм-аут автостарта:** Измените в "Настройки" (по умолчанию 600 сек).
- **Перемещение окна:** В "Настройки" выберите "Изменить положение" и нажмите пробел для фиксации.
- **Клавиша активации:** Переопределите в "Настройки" через нажатие на текущую клавишу.
- **Профили:** Выберите и сохраните один из трёх профилей в "Настройки" (сохранение автоматическое).
- **Логирование:** Включите/выключите в "Настройки".
- **Сброс настроек:** Нажмите "Сбросить все настройки" в "Настройки".

### Интерфейс
- **Флудер:** Настройка интервала, паузы и режима работы.
- **Настройки:** Управление окнами, профилями, клавишами и сбросом.
- **Информация:** Описание функций, версии, ссылки и благодарности.
- **Статистика:** Время работы, попытки, репорты, флуды с функцией сброса.
- **ChangeLog:** История обновлений скрипта.
